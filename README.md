# Nestly

A full-stack marketplace for discovering, comparing, and managing long-term rentals.

## Features

- Search and filter rental listings
- Saved properties and inquiry flows
- Owner and operations workspaces
- Typed database layer and background worker

## Stack

Next.js, TypeScript, Drizzle ORM, PostgreSQL, Cloudflare Workers.

## Run locally

```bash
npm install
npm run dev
```
